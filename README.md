# 🍽️ NextPlate

**NextPlate** is a Smart QR Menu & Restaurant Management System that helps restaurants provide a modern digital dining experience.

Customers can scan a QR code, browse the menu, view dishes in 3D, place orders, call a waiter, split bills, and enjoy a seamless restaurant experience.

---

## 🚀 Features

### 👤 Customer App
- 📱 QR Code Menu
- 🍽️ Smart Digital Menu
- 🔍 Search Dishes
- 🥗 Veg / Non-Veg Filter
- ⭐ Ratings & Reviews
- ❤️ Favorite Dishes
- 🛒 Add to Cart
- 🍛 Half / Full Selection
- 👨‍🍳 3D Food Preview
- 🧾 Split Bill
- 🛎️ Call Waiter
- 🌐 Multi Language Support

---

### 👨‍💼 Restaurant Admin
- 📋 Menu Management
- ➕ Add / Edit / Delete Dishes
- 🔴 Live Orders
- 👥 Customer Count
- 💰 Revenue Dashboard
- 📊 Sales Statistics
- ⚙️ Restaurant Settings
